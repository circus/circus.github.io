Weighted Attribute Grammars Oriented Notation (WAGon)

WAGon is a Library/Ecosystem/Proof-of-Concept for working with Weighted Attribute Grammars.

WAGon is designed for researchers and language designers experimenting with WAGs such that they do not have to waste time creating a DSL and parser and can start immediately experimenting with the format itself.

You can read the master thesis which explains more in detail what WAGon is, what WAGon's WAGs are, and why you should care.

WAGon consists out of the following crates:

  • wagon-parser
    • This crate is the main entrypoint for any language designer who wants to use WAGs.
  • wagon-codegen
    • Various methods that are generally useful for performing code generation when working with WAGon.
  • wagon-lexer
    • Lexer for the WAGon DSL.
  • wagon-value
    • Pseudo-dynamically typed values as defined by the WAGon DSL.
  • wagon-utils
    • Utility methods used in the WAGon ecosystem.
  • wagon-macros
    • Various build-time macros used in the WAGon ecosystem.
  • wagon-ident
    • Centralized location for attribute identifiers in WAGon.
